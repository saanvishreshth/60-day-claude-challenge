# Day 49 – Personal AI Playbook

## Steps

1. Read the provided resources.
2. Watch the solution video.
3. Open Claude and set **Effort Level** to **Low**.
4. Start a new conversation.
5. Paste the **Personal AI Playbook** prompt.
6. Answer Claude's interview questions about your role, use cases, and bottlenecks.
7. Generate the complete **HTML application**.
8. Save the generated file as **index.html**.
9. Open it locally in your browser.
10. Explore your personalized workflow library.
11. Assemble a prompt using the **Prompt Builder**.
12. Convert the prompt into an autonomous loop using the **Loop Builder**.
13. Save, favorite, and search your workflows.
14. Export your workflow library as a backup **JSON** file.
15. Take screenshots.
16. Create a **Day49** folder in your GitHub repository.
17. Create a **day49.md** file.
18. Upload the HTML file, screenshots, exported workflow JSON, and key learnings.
19. Commit and push the changes.
20. Submit the GitHub commit URL.

# What You'll Learn

- Building a personalized AI workflow library.
- Creating prompts with the Prompt Builder.
- Converting prompts into autonomous workflows.
- Organizing, searching, and managing AI workflows.
- Exporting workflow libraries for backup and reuse.
- Designing a responsive HTML application with Claude.
- Managing and documenting projects using GitHub.
