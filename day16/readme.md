# Day 16 – Custom Claude Skill: Stock Fundamental Research

## Objective

The objective of this activity was to create a reusable Claude Custom Skill for conducting stock fundamental research and investment analysis.

## Tools Used

* Claude AI
* Custom Skills Feature
* Financial Market Data
* GitHub

## Skill Details

### Skill Name

stock-fundamental-research

### Purpose

To analyze stocks using financial metrics, valuation methods, ownership patterns, competitive analysis, and risk assessment.

## Stocks Analyzed

* TCS
* Infosys
* Reliance Industries

## Key Areas Reviewed

* Business Overview
* Financial Performance
* Revenue Growth
* Profitability
* Valuation Metrics
* Shareholding Pattern
* Risk Factors
* Investment Outlook

## Key Learnings

* Learned how to create reusable AI skills.
* Understood stock valuation concepts.
* Explored financial statement analysis.
* Compared multiple stocks using structured frameworks.
* Learned how AI can automate research workflows.

## Outcome

Successfully created and tested a reusable stock research skill capable of generating detailed investment analysis reports without repeatedly entering prompts.
