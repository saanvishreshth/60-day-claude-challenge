# Day 40 – AI Assistant Builder

## Objective
Built a customizable AI Assistant Builder using Claude that generates a complete HTML application with an editable system prompt and documentation.

## Files
- index.html
- system-prompt.txt
- screenshots/
- day40.md

## Features Explored
- AI Assistant Builder
- MCQ-based assistant configuration
- Generated system prompt
- Documentation panel
- Claude Artifact publishing
- HTML export

## Key Learnings
- Claude Artifacts can run AI assistants without requiring an Anthropic API key.
- Downloaded HTML requires a valid Anthropic API key for live API calls.
- System prompts define the assistant's behavior and personality.
- Documentation panel helps understand the generated application.
- Publishing as a Claude Artifact simplifies testing and sharing.
