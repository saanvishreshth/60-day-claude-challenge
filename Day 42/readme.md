# Day 42 – Personal Financial Command Center

## Objective

The objective of this project was to build and explore a **Personal Financial Command Center** using Claude AI. The application helps users analyze their financial health, visualize spending, explore budgeting options, and receive AI-powered financial recommendations.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Claude AI
