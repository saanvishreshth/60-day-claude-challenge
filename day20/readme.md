# Day 20 – Face Puzzle Game

## Objective

Build and test a Face Puzzle Game using AI-generated HTML.

## Features Implemented

* Webcam photo capture
* Image puzzle generator
* Difficulty selection (3×3, 4×4, 5×5)
* Drag-and-drop support
* Touch interactions
* Move counter
* Timer
* Local leaderboard

## Testing Performed

* Drag-and-drop tested

* Timer verified
* Leaderboard verified
