Architecture Overview
Planner builds an SEO outline + keyword map once, up front.
Executor writes the first full draft from that plan.
Evaluator scores the current draft against the SEO rubric every round, live.
Critic reads the evaluation and pinpoints concrete weaknesses.
Improver rewrites the draft using the critique — its output becomes next round's input to Evaluator.
Memory Manager logs durable learnings (recurring issues, what worked) so later rounds don't repeat mistakes.
Final Reviewer runs once, after a stop condition fires, to sign off on the article that exits the loop.
The stop-check (plateau → threshold → hard cap) runs after every round and decides whether state flows back into another Evaluator call or forward to the Final Reviewer.
Extension Ideas
• Add a Safety Monitor agent for brand/compliance checks before publish.
• Parallelize Evaluator + Critic calls to cut latency per round.
• Give Memory Manager persistent storage across sessions to build a style guide over time.
• Add a human-in-the-loop approval gate before Final Reviewer signs off.
• Swap the rubric to plug in different domains (code review, research reports, ad copy) with the same loop.
